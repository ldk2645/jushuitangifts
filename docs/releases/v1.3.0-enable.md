# v1.3.0 编码精确匹配与向下填充

## 功能

商品编码以完整原字符串匹配，大小写、前导零和标点均有意义。编码不进入模糊候选，疑似错误编码保持未匹配，不借名称/别名补猜。搜索框、公式栏与粘贴规则一致，且编码必须属于当前分组。名称/别名继续支持匹配。

选区右下角绿色填充柄支持向下拖动：单行重复、多行循环，可扩展新行，最多 10000 行。订单号与编码保持字符串，绝不按数字递增。Ctrl+D 用选区首行填充下方；双击填充柄按相邻可编辑列的连续内容确定末行。拖至底部自动滚动；Esc、窗口失焦或指针取消均不落盘，一次填充对应一次撤销。

筛选时只填可见行，不改隐藏行、不额外新增行。状态列、行 ID、人工状态、收件信息和旧改地址标记不从来源复制。已选编码与未匹配内容一起保留，不能变成可提交的部分匹配。组外、失效分组和填充期间表格/范围变化均整次拒绝。填充只编辑草稿，不调用登记或重登。同时修正三列的 Tab/Shift+Tab、End 及状态列清空判断。

礼品名称和别名匹配忽略大小写。例如，输入 `air4 se` 可匹配“小米 Air4 SE”。订单号录入和粘贴会去除首尾空格，保留前导零与中间字符。
