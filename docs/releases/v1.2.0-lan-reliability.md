# v1.2.0 局域网通信检查与修复

日期：2026-11-02。

## 已确认的问题与修复

1. 普通 HTTP 内网地址不提供 `crypto.randomUUID()`。此前仅在本机回环地址验收，漏掉空表载入、添加行、扩展粘贴时的异常。现在使用 `getRandomValues()` 生成随机 UUID v4 作为兼容路径，不影响既有行 ID、任务身份或历史。浏览器依据：[randomUUID 的安全上下文限制](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)、[getRandomValues 支持非安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues)。
2. 主机重启后旧页面携带的 CSRF 失效，过去提示刷新可能让用户丢失编辑。服务端现在明确区分同源请求的过期凭据和跨站拒绝；前端只读获取新凭据，保留编辑并提示再次明确操作，不自动重放任何写请求。重新保存仍校验草稿 revision。
3. 前端请求没有主动超时、状态轮询失败不提示。现在读取超时 15 秒，写入超时 60 秒；断线显示最后已知状态并保留输入，恢复后只读继续轮询。写入超时不代表请求未执行，不会自动再次发送登记。
4. 直接运行 main.py 的重复启动检测仍使用系统代理，且两个启动入口都漏查共享子网。现在都直连回环健康接口，核对启用状态、IP、域名与子网；仅子网变化或旧服务未报告子网时也要求正常重启。
5. 网络探测要求物理网卡必须有默认网关，漏掉同网段直连、静态地址等不需要互联网网关的局域网。现在允许无网关的物理私有 IPv4 网卡，仍排除虚拟网卡和公网地址。
6. 从本机使用域名/IP 访问时，平台登录按钮曾仅按连接来源判定。现在与其余主机操作一致，须同时使用回环访问地址；不采信代理转发头。

## 安全与数据范围

- 没有更改 DNS、hosts、代理、网络配置或 Windows 防火墙。
- 没有重启真实工作台、生成真实任务、提交平台订单或改写任务历史。
- 保留现场礼品目录及用户操作产生的改动，不同步或覆盖 U 盘副本。
- 服务重启、超时与断线均不放宽鉴权、CSRF、版本冲突或单次提交约束。

## 验证

- 546 项 unittest 回归通过，包含过期凭据拒绝写入、子网变化检查、代理绕过和无网关探测。
- 普通 HTTP 域名 Selenium：修复前空表初始化超时；修复后空表、加行、扩展粘贴、旧凭据只读恢复、写请求不重放、超时和断线提醒通过。
- 双客户端 Selenium：访问鉴权、共享草稿冲突、同任务防重、回环免登录及网络提醒通过。修正旧验收脚本对隐藏保存标签的读取；冲突场景先进入编辑保留旧版本，避免把正常后台同步误判为未触发冲突。
- 所有浏览器测试使用临时目录、独立配置和合成数据。本机监听、网卡及已有防火墙规则仅只读核查；没有从另一台真实设备完成端到端验收。

启用修复需等待业务结束后正常关闭并重新启动工作台，再刷新客户端页面；有未保存内容时先保留。旧版本 U 盘副本需单独升级后才包含这些修复。
