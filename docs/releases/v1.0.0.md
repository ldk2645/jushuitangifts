# Version 1 — v1.0.0

首次发布日期：2026-10-25；当前替换版本更新：2026-10-26。运行环境：Windows、Python 3.12、Chrome。保留版本号及原发布链接，`v1.0.0` 标签指向当前更新提交。

## 功能

- 本地表格工作台：批量新增、Excel 粘贴、礼品多选与模糊匹配、新增礼赠、草稿保存、撤销及列宽偏好。
- 真实 Selenium 业务流程：聚水潭保存查询基线，班牛在同一任务加入全部礼品并提交一次，读取回执后回聚水潭核对新增记录与数量。
- 持久化串行任务与防重复机制：重复点击、复制相同业务及重启不会再次提交；失败、超时或结果不确定时保留终态，需人工核查。
- 各平台独立浏览器配置，DPAPI 加密会话与本机账号配置；会话过期后自动尝试一次密码登录，验证码和二次验证由人工处理。
- 登录配置占用前置检查，以及有界保存、独立关闭和失败后的明确关闭提示。
- 多订单及跨批次复用平台浏览器；确认旧窗口已关闭时重建浏览器及页面适配器。详情遮罩、透明加载层及列表未刷新均有保护。
- 班牛异步同步最多 8 轮只读回执核验；仅确认“成功”及新单号后再核验聚水潭新增礼品。失败后的安全表单清理不重放提交。
- 可选局域网共享：主机回环地址免登录，其他设备使用独立六位数字密码；网络或 IP 变化时提醒核对 Cloudflare DNS。
- 扩充礼品清单，支持多个礼品按空格匹配和按最近订单使用频率排列；同名歧义保留人工选择。

当前发布回归的 **381 项单元测试通过**，使用隔离数据与显式业务替身，覆盖任务防重、提交次数、新增信息核验、登录边界、失效浏览器重建、Windows 同时钟值的结果排序、局域网访问及网络提醒。隔离 Chrome 验收覆盖工作台编辑与粘贴、保存和只读状态轮询、草稿冲突、任务防重、礼品扩充、旧地址草稿关闭，以及两个共享客户端的访问控制与网络提醒。另已通过页面复用、未提交表单清理和关闭最后一个窗口后恢复的本地 Chrome 验收。以上隔离验收不向真实平台提交礼赠任务。

随版本提供 Windows / Python 3.12 的 GitHub Actions 单元测试。`main.py --version` 输出 `1.0.0`；`example.md` 中的两个订单号为合成演示数据。

历史真实平台验证分开记录：2026-10-24 完成自动登记端到端验证；2026-10-25 验证两站密码登录及加密快照保存；2026-10-26 业务运行及只读核对覆盖班牛回执与聚水潭新增记录，并核对过同编码商品名称差异。发布整理期间不再次提交真实订单；隔离测试通过不等于所有真实订单场景均已验证。

## 限制与升级

- 仅支持原地址礼赠，不读取或核对收件信息。页面禁用新开启改地址；旧草稿可关闭改地址，仍携带改地址的任务在平台查询、提交前失败。
- 不提供失败任务的自动或人工重试入口。平台字段、权限或页面发生变化后，需要重新核对适配。
- GitHub 仓库与发布包不包含本机账号、登录会话、浏览器配置、用户草稿、任务记录及含真实订单的内部历史材料。
- 升级前正常关闭程序，备份并保留 `data/`、`config/accounts.local.json` 和自行维护的 `config/gifts.json`。尤其要保留 `data/registration_jobs/` 中的防重记录。DPAPI 数据绑定当前 Windows 用户，换电脑后需重新配置登录。
