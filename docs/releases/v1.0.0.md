# Version 1 — v1.0.0

发布日期：2026-10-25。运行环境：Windows、Python 3.12、Chrome。

## 功能

- 本地表格工作台：批量新增、Excel 粘贴、礼品多选与模糊匹配、新增礼赠、草稿保存、撤销及列宽偏好。
- 真实 Selenium 业务流程：聚水潭保存查询基线，班牛在同一任务加入全部礼品并提交一次，读取回执后回聚水潭核对新增记录与数量。
- 持久化串行任务与防重复机制：重复点击、复制相同业务及重启不会再次提交；失败、超时或结果不确定时保留终态，需人工核查。
- 各平台独立浏览器配置，DPAPI 加密会话与本机账号配置；会话过期后自动尝试一次密码登录，验证码和二次验证由人工处理。
- 登录配置占用前置检查，以及有界保存、独立关闭和失败后的明确关闭提示。

## 验证范围

发布回归的 **290 项单元测试通过**，使用隔离数据与显式业务替身，覆盖任务防重、提交次数、新增信息核验、登录边界及前端接口。本地 Chrome 工作台验收通过，覆盖真实双击编辑、粘贴、保存、状态轮询、防重、登录占用提示，以及隔离目录中的新增礼赠与刷新恢复；会话保存恢复、关闭行为及班牛列表的 12 个 DOM 场景也全部通过。这些测试不向真实平台提交礼赠任务。

随版本提供 Windows / Python 3.12 的 GitHub Actions 单元测试。`main.py --version` 输出 `1.0.0`；`example.md` 中的两个订单号为合成演示数据。

历史真实平台验证分开记录：2026-10-24 完成一次自动登记端到端验证，班牛回传单号与聚水潭新增礼品、数量一致；2026-10-25 使用独立临时浏览器配置验证两站密码登录、业务入口确认及加密快照保存。后者仅验证登录，没有创建礼赠任务。本轮发布整理不重复执行这些真实业务提交。

## 限制与升级

- 仅支持原地址礼赠，不读取或核对收件信息。勾选改地址的任务在平台查询、提交前失败。
- 不提供失败任务的自动或人工重试入口。平台字段、权限或页面发生变化后，需要重新核对适配。
- GitHub 仓库与发布包不包含本机账号、登录会话、浏览器配置、用户草稿、任务记录及含真实订单的内部历史材料。
- 升级前正常关闭程序，备份并保留 `data/`、`config/accounts.local.json` 和自行维护的 `config/gifts.json`。尤其要保留 `data/registration_jobs/` 中的防重记录。DPAPI 数据绑定当前 Windows 用户，换电脑后需重新配置登录。
