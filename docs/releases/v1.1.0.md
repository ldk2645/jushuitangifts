# v1.1.0

本版本增加主机失败重登和今日日志 Excel 导出，并将普通登记的防重范围扩大为订单号。

## 使用

- 主机使用 `http://127.0.0.1:8765/` 或 `http://localhost:8765/`，点击“重新登记失败订单”，核对保存的订单与礼品后点“核查并重登”。旧失败记录保留，重复点击同一记录不会产生多个任务。
- 只有能确定尚未提交的失败订单可进入重登核查。聚水潭基线变化、班牛已有任务、已提交或结果不确定时停止，不重新提交。
- “导出今日日志”下载两个工作表：成功登记包含原订单号与本次新增内部订单号；失败登记包含订单号与失败原因。按主机日期和实际完成时间统计，同一次执行的复制结果不重复计数；先失败后重登成功会保留两条执行记录。
- 局域网设备可继续使用普通登记；主机重登和导出仅限本机回环访问，转发头及局域网密码不能越权。
- 普通开始登记始终跳过已有成功或失败的订单，即使礼品变更、换行、换批次或重启。不同礼品的重复行显示“已跳过”。

## 数据兼容

保留 `data/`、`config/accounts.local.json`、局域网配置及本机礼品目录。新执行历史保存在 `data/registration_jobs/execution_history/`，须随任务目录一起备份。旧记录证据不足时不开放重登。升级前正常退出旧工作台与登录助手，再重新启动工作台。

## 验证

404 项单元测试通过，覆盖订单号防重、跨批次并发、主机权限、重登请求幂等、重启中断、不确定提交拦截、提交前再次查重、历史兼容和日志日期／去重。

`tests/smoke_frontend.py` 与 `tests/smoke_host_management.py` 的隔离 Chrome 验收通过，覆盖原表格交互、新按钮、一次重登、普通开始跳过及 Excel 下载。导出样例经过 LibreOffice 打开并重新保存，两个工作表、长订单号与前导零均保持完整；未更改默认办公软件。

所有验收使用合成订单、临时任务目录及浏览器配置。真实平台的失败重登尚未执行；隔离测试通过不等于真实平台登记通过。
