## 2026-11-05 平台登录只打开一个平台浏览器的排查

现象：目标电脑点“平台登录”只打开了聚水潭浏览器，班牛浏览器打不开。本机已复现同类失败：上一轮登记任务遗留的班牛 headless Chrome 仍占用 `data/browser/banniu` 配置，再次用同一配置创建浏览器时 Selenium 直接抛 `SessionNotCreatedException: Chrome failed to start: crashed`；聚水潭配置空闲，所以它的窗口能正常打开。登录助手已改为在该平台行显示异常类名；`SessionNotCreatedException` 时附带“浏览器窗口或后台进程可能仍占用登录配置”的提示。

新增排查入口：`diagnose-login.bat` + `tools/check_login_startup.py`。它只读检查：浏览器模式（普通版 Chrome / 便携版 Edge）、Windows 完整性级别、登录配置锁、会话与账号 DPAPI 能否解密、浏览器配置目录残留文件，以及 `DevToolsActivePort` 是否仍被另一个本工具浏览器占用；再分别尝试两个平台的浏览器启动、登录页导航和登录状态，报告写入 `.tmp/login-diagnostic.json`，不包含账号密码，不提交业务。所有诊断/更新批处理同时支持普通 `.venv` 与便携包 `runtime\python.exe`；`build_portable.py` 会把 diagnose-login、diagnose-selenium、fix-browser-integrity、verify-honor、update-gifts 及对应 tools 一并打包。

目标电脑排查顺序：先 stop.bat / 关闭全部本工具窗口和遗留浏览器 → 运行 diagnose-login.bat → 若报告某平台 profile_in_use，结束任务管理器中命令行含 `data\browser\banniu`（便携版 `data\browser_edge\banniu`）的 Chrome/Edge 进程后重试；若 create_driver 失败且完整性级别 low 或 `SessionNotCreatedException`，运行 fix-browser-integrity.bat；若配置目录无法重建，改名 `.bak` 后由程序重建；若 navigate 失败检查目标电脑能否访问班牛站点；换电脑后旧加密会话/密码只影响自动登录，手动登录并保存即可。

本机诊断复现记录见 `.tmp/login-diagnostic-direct.txt`（班牛配置被占用时 create_driver 阶段 SessionNotCreatedException）；回归测试 620 项通过。

## 2026-11-05 update-gifts.bat 修复

现象：双击 update-gifts.bat 后 191 个编码全部显示“名称待核实（保留原名，仅更新分组）”，没有任何名称写入；21:55–21:58 的四次报告（`txt-81fbc2ff…`、`txt-482aaf2d…`、`txt-e40f24ed…`、`txt-1046da90…`）证据中 191 条班牛观察全部 `blocked`，原因均为“班牛查询表单归属标记缺失或被外部替换”。

根因有两个：

1. 稳定性重构把表单归属标记统一为 `__giftRegistrationOwner`，商品查询读取器仍读取旧的 `__giftProductQueryOwner`，因此任何新建空白表单都被判定归属缺失，所有编码在开始查询前即被阻断。已统一读取同一个归属标记，并保留人工编辑/提交/替换表单的原有保护。
2. 班牛加密会话快照已过期（16:34 保存），自动登录未确认成功；旧实现只输出笼统的“名称待核实”，无法看出是登录问题。商品查询读取器新增人工登录等待：班牛未登录时保留可见浏览器并提示，默认最多等待 300 秒（`--login-wait 秒数` 调整，0 或 `--headless` 不等待）；登录成功后自动保存加密会话并继续全部编码查询，超时/失败时在报告和命令行显示实际原因。

同时改进：update-gifts 命令行按原因合并显示“名称待核实/阻止应用”（不再逐行刷 191 条），`catalog_import` 把班牛实际失败原因写入 pending/name_pending，报告保留逐项明细。验证：单元测试 666 项通过（新增人工登录等待、超时、无头不等待、参数校验等）；本机 3 编码探针在班牛未登录时正确输出人工登录提示，超时后给出带原因的结果（`.tmp/update-gifts-loginwait-probe.txt`），原先的归属标记错误不再出现。真实 191 编码全量更新需在班牛浏览器窗口完成一次登录（本机会话已过期，自动化不能代替人工验证码/密码），登录后直接双击 update-gifts.bat 即可继续。
