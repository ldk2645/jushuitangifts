# v1.1.1

本版本增加礼品分组、状态筛选、凌晨归档与失败订单的延迟只读复核，保留原表格交互和按订单号防重复提交规则。

## 使用

- 礼品选择框支持“全部礼品”“未分组”“小米生态链”“小米手机”筛选。现有礼品保持未分组，由主机打开“管理”批量分配；同一礼品可属于多个分组，也能新增分组。局域网设备可使用分组筛选，不能修改分组归属。
- 状态列下拉筛选控制可见行，复制、粘贴、清空及删除仅影响可见行；普通“开始登记”仍检查完整已保存草稿并跳过历史成功／失败订单。
- 北京时间每天 01:00 自动导出上一日日志到 `data/exports/`，导出成功并完成草稿备份后清理表格成功行。失败行、未执行行、修改过的行和防重历史保留。原草稿备份在 `data/draft_archive/`。
- 新失败任务 10 分钟后自动查询聚水潭复核一次。只有本次新增礼品及数量与请求吻合、且具有完整基线和提交依据时更新为成功。无新增、信息不符、缺少证据或查询异常则保留失败。复核绝不再次提交班牛。

## 运行与兼容

工作台必须运行才能执行后台任务。登记队列忙时等待空闲。首次升级从下一个 01:00 开始，不立即清理当前表格；之后停机错过的归档将在重启后逐日补做。复核已领取后若异常中断，重启不重放。

保留 `data/`、登录配置和本机礼品目录，并将新增的 `config/gift_groups.local.json` 一起备份。分组只保存元数据，不改商品编码或原登记内容。旧失败记录若无复核调度信息，不会因升级而批量查询或重新登记。

复核成功保留原登记完成日期，已自动导出的对应日期文件会更新；用户此前下载的文件不会被远程修改。表格的后台清理通过 revision 同步，存在未保存输入时保留本地内容并提示处理冲突。

## 2026-10-27 边界修复

- 公式栏正在编辑时暂停后台草稿替换和筛选重绘；请求发出后开始输入也会在响应返回时再次检查。未确认的输入参与冲突及离页保护，Ctrl+S 先提交公式栏输入再保存。
- 行显示归属与业务结果更新时间分开保存。旧订单的自动复核保留原行归属，不覆盖同一行后来登记的订单；明确再次开始旧草稿时仍可显示其已核验结果，且不重复提交。
- 程序中断后恢复为失败的原地址任务安排 10 分钟后一次只读复核。无完整基线或提交依据时保持失败；已领取过的复核仍不重放，升级前普通历史失败不批量补登。
- 清理重试时核对备份内容。草稿变化后保存带 revision 和内容摘要的新快照，保留原备份；新备份未成功落盘时不删除行。

## 等待时间与 U 盘便携包

- 班牛拉单确认由 20 秒延长至 60 秒，不重复回车；回执只读核验由 8 轮、间隔 3 秒调整为 24 轮、间隔 5 秒（另计页面加载时间）。暂时无效或旧回传号在同一新增任务内继续等待，信息不符及明确同步失败仍立即拒绝，不再次提交。
- 提供 `GIFT_CHROMEDRIVER` 显式驱动路径，便携包固定相对路径的 Chrome 和驱动，不依赖目标电脑的 Chrome 或首次联网下载驱动。
- 便携版自带 Python 3.12、Tk 和 Selenium，使用 8766 端口、仅本机访问。包含制作时的草稿、分组和完整防重复任务历史；换电脑重新登录并保存当前 Windows 用户的加密凭据。
- 等待和驱动调整后 441 项单元测试通过；便携环境验证使用隔离数据，不代表真实平台登记通过。
