# 2026-11-13 提交后的失败显示为待人工核查

按用户选择，仅细分前端失败状态：

- 自动结果为失败，且有班牛提交按钮点击、已接受回执、已提交阶段、已进入复查阶段或明确人工提交记录时，显示橙黄色“待人工核查”。
- 其他失败仍显示红色“失败”。仅有尝试次数或“正在登记”阶段不能证明已提交，填表失败不会被误列为待人工核查。

状态列筛选、概况计数、底部汇总以及重登列表同步展示此分类。“待人工核查”在状态列和重登面板均不显示重登按钮，也不进入前端批量重登名单；普通失败行保留原有重登入口。原有人工标记优先级保持不变；“人工待核查”仍是人工主动设置的标记，和自动分类“待人工核查”分别保留。

后端状态和历史记录仍保存原来的 `failed`，只在状态与失败列表响应中增加派生字段 `submitted_to_banniu`。不改提交过程、复核标准、复核时间、重登资格、防重判断、日志导出或已保存订单。已有重登入口沿用原资格校验；自动复核成功后按原逻辑更新为成功并移出待人工核查筛选。

验证：93 项状态、工作流、人工管理、重启恢复和前端服务测试通过；浏览器验收覆盖失败分类、颜色、统计、筛选、人工标记覆盖、重登资格和复核成功后的状态刷新。全部测试使用隔离目录及合成订单。
