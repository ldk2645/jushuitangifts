# 2026-11-12 聚水潭内部订单号复核修复

首次核验和失败 180 秒后的自动复核共用以下成功规则：班牛有效回执的内部订单号，在同一线上订单的聚水潭查询结果中出现，且提交前基线中不存在，即确认登记成功。

- 聚水潭复核只读取线上订单号和内部订单号，不再依赖商品明细展开、商品编码或数量展示。
- 其它新增订单不影响本次结果；成功日志只保存与回执匹配的内部订单号。回执包含多个单号时必须全部匹配。
- 编号使用完整字符串比较，保留前导零。旧单、错误线上订单、缺失回执、拒绝回执和未确认刷新的页面仍不能判成功。
- 班牛回执轮询以提交前的完整任务 ID 基线及唯一新增任务确认归属，不再用班牛创建时间与本机点击时间比较，避免两端时钟偏差误判。
- 聚水潭短轮询遇到其它新增订单时继续等待回执对应单号，不提前结束。本次修改不会再次提交班牛。
- 仅有关联字符串、没有内部订单号的历史回执保留原核验规则。

修改位于当前 NL 主项目。正常结束当前任务并重启工作台后加载新代码。已完成的历史复核不会自动重新执行，缺少有效回执的历史失败也不会被直接改成成功。
