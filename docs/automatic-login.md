# 会话过期自动登录

荣耀版更新日期：2026-11-05。

登录助手及真实 Selenium 页面操作已接入 `SessionAuthenticator`。优先复用浏览器配置与加密会话；出现已核对的登录表单时，读取 `config/accounts.local.json` 的 DPAPI 凭据，在内存中解密并通过 Selenium 填写。此模块不执行业务登记。

## 页面与判断

| 平台 | 已核对的登录控件 | 恢复后必须确认 |
| --- | --- | --- |
| 聚水潭 | `dopre.jushuitan.com/login.aspx`；`#login_id`、`#password`、`#agreementCheck`、`div#login-sub` | 订单入口的 `#_jt_body` 及 `iframe#s_filter_frame` |
| 班牛 | 原项目相同入口 `https://work.bytenew.com/`，跳转 `app.html#/login`；手机号码／邮箱输入、密码输入、`button.login-main-body-button-btn` | 目标路径 `#/applet/appNew/projectNew/58231/27715` 和标题“聚水谭赠品补发—荣耀”必须同时匹配 |

输入密码前必须是准确的 HTTPS 官方主机和已观察表单，不能仅凭“页面含密码框”或通用站点域名后缀发送凭据。成功必须看到正向业务标记；隐藏密码框、关闭弹窗或后台残留标题均不足以成功。

聚水潭实测会出现密码年龄提醒。仅对已核对的精确文案“注意：您的密码已经超过3个月未修改(304)，请您尽快修改密码！”单次点击对应“确认”；不修改密码，也不处理其它修改密码流程。荣耀班牛账号登录后先进入“赠品补发看板——荣耀”，确认实际看板路径、标题且登录控件消失后，再单次导航到荣耀登记工作表。

## 有界与防重复

- 同一浏览器实例的同轮失效最多进行一次自动账号密码登录。失败、超时或验证要求会锁存，五秒保存轮询不重复发送密码；只有正向业务页面确认后才解除锁存。
- 手动完成验证后，若落在聚水潭首页或班牛其它工作表，可只读进入已知目标入口确认，不重新读取或发送密码。
- 登录等待有界，关闭助手会取消后续登录步骤；`capture()`、`close()` 不会触发登录。
- 登录页或验证码阶段不能覆盖上次完整 DPAPI 快照。登录恢复后保存新快照，保存暂时失败则保留旧快照并提示，后续成功保存会清除过时警告。
- 只读订单／任务查询仅在认证实际恢复后最多完整重查一次。登记表单失效后不重新填写；提交异常不重调提交函数、不再次点击。提交后继续读取回执时沿用原基线与提交时间。
- 不重置既有业务失败终态、提交尝试计数或防重记录。

关闭平台浏览器后的失效 WebDriver 会话与账号密码错误分别处理。业务层在获取页面时只读检查窗口句柄；明确会话失效或无窗口，才清理原驱动并在原配置锁内重建浏览器，同时替换缓存的页面适配器。无法确认关闭、旧浏览器清理失败时不新开浏览器。此恢复不包裹提交动作，不会重放失效前的登记，也不会解除既有失败任务的防重。

## 目标电脑排查

登录助手只打开一个平台浏览器，或该平台行提示“浏览器启动未完成（…）”时，按 README 的“平台登录只打开一个平台浏览器时”处理；先运行 diagnose-login.bat 生成 `.tmp/login-diagnostic.json`。最常见原因是该平台浏览器配置仍被遗留的本工具浏览器进程占用（另一个平台配置空闲时窗口仍能打开）；其余按报告中的启动阶段、完整性级别、配置文件锁与 DPAPI 解密状态定位。换电脑后旧电脑的 `data/sessions/*.dpapi` 与 `accounts.local.json` 无法跨 Windows 用户解密，只会影响自动登录，不影响浏览器窗口打开；手动登录并保存即可。

## 验证记录

荣耀版于 2026-11-05 通过独立内置浏览器验证了新账号登录、荣耀看板跳转和登记工作表。Selenium 的 Chrome 启动退出、Edge 页面崩溃问题仍存在；该只读页面核对不能代替 Selenium 登录、快照保存或实际订单登记验收。

以下是原项目历史验证，不代表荣耀版已通过：2026-10-25 使用两个平台真实页面、独立临时 Chrome 配置和当时的加密账号配置，验证了自动输入账号密码、登录提醒／默认页面处理、进入对应业务入口、正向登录状态以及加密快照保存。两站均通过。未退出或清空生产浏览器配置，未创建或提交任何礼赠任务。

单元测试使用显式 fake 凭据和页面，覆盖可信来源、错误／验证锁存、取消、手动恢复、查询重查上限及提交不重试。真实登录验证不等于再次执行实单登记，已有业务的防重记录保持原样。

原项目的本地 Chrome 工作台验收和合成会话保存恢复验收均通过。历史发布回归的结果见 [v1.0.0 发布说明](releases/v1.0.0.md)。账号、原始页面、运行日志和真实业务数据不随代码发布。

升级前确认任务已终态，正常关闭工作台和登录助手，备份并保留本机 `data/` 与账号配置。重启后刷新工作台页面，新开的登录助手会使用当前自动登录流程；升级不会重新派发已有任务。
