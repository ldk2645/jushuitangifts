# U 盘便携版：无域名局域网使用说明

适用：Windows 10/11 64 位主机。同一局域网的其他电脑、手机只需浏览器，不需要安装 Python、Chrome 或本工具。**不用域名，也不用 Cloudflare。**

## 首次在目标电脑配置

1. 将 U 盘接到负责运行工具的主机，打开 `gifts` 文件夹。盘符可以改变，以下操作都在这个文件夹中完成。主机连接目标 Wi-Fi 或有线局域网，其他设备连接同一个局域网。
2. 若工作台已打开，先双击 `stop.bat`，等待工作台和业务浏览器正常关闭。不要在登记过程中拔 U 盘。
3. 双击 **`lan-setup.bat`**。窗口会列出可用物理网络的名称、IP 和子网；输入要共享的网络编号并回车。例如选择显示 `192.168.1.100` 的网卡。不要照抄示例 IP，程序会保存选中网卡的实际 IP/子网。
4. 弹出的“局域网访问”窗口会显示访问地址、用户名和密码。用户名固定为 **`gift`**，独立密码为六位数字（可能以 0 开头）；点击“显示 / 隐藏”或“复制访问密码”。密码不是聚水潭或班牛的密码。
5. 右键 **`allow-lan.bat` → 以管理员身份运行**，同意 Windows 提示。脚本只为当前选中网卡/IP、对应局域网子网和 TCP 8766 端口添加本工具防火墙规则。不需要关闭整个防火墙，也不需要路由器公网端口映射。
6. 双击 **`start.bat`**，保持启动窗口和主机运行。主机使用 **http://127.0.0.1:8766/**，免工作台访问密码。
7. 在另一台设备打开“局域网访问”窗口显示的地址。例如主机 IP 为 `192.168.1.100`，访问 **http://192.168.1.100:8766/**，输入 `gift` 和六位密码。其他设备不能使用 `127.0.0.1`，那指向它自己。

以后双击 **`lan-info.bat`** 可以再次查看地址和密码。请在目标电脑上操作这些步骤；不应提前把另一台电脑的 IP 配置复制过去。

## 平台登录与日常使用

- 首次换电脑，主机点“平台登录”或双击 `login.bat`，完成两个平台的登录/验证码，保存并关闭登录助手。若需要账号密码自动登录，可运行 `accounts.bat` 在该电脑加密保存。
- 礼品、草稿、任务队列和登记历史由主机统一保存，其他设备打开的是同一工作台。登录、失败订单重登、日志导出等主机管理操作，应在主机通过 `127.0.0.1:8766` 执行。
- 主机必须开机、保持已登录的 Windows 会话、工作台运行且不休眠。主机关机、断网、拔掉 U 盘后，其他设备无法使用。
- 关闭时运行 `stop.bat`，等待在途任务结束和浏览器退出，再安全弹出 U 盘。源电脑原项目和 U 盘副本不会自动同步新增历史，同一业务固定使用一份。

## 更换网络、IP 或电脑

IP 不变时，重新启动 `start.bat` 即可。IP 或网络变化时：正常退出工作台，重新运行 `lan-setup.bat` 选择新网络，再以管理员身份运行 `allow-lan.bat`，重新启动工作台，并将新访问地址告诉其他设备。**无域名模式不用修改 DNS**。建议在路由器上为主机设置 DHCP 地址保留，减少 IP 变化。

访问密码由当前 Windows 用户加密。换电脑/Windows 用户后，如果提示访问凭据不能解密：先关闭便携版，把 `data\lan_access.dpapi` 重命名备份（例如 `lan_access.old.dpapi`），再运行 `lan-setup.bat` 生成新密码。只处理这一访问密码文件，**不要删除草稿、`registration_jobs` 或账号配置来解决访问问题**。平台登录在新电脑重新完成；账号加密配置可用 `accounts.bat` 重新保存。

## 打不开时检查

| 现象 | 处理 |
| --- | --- |
| 主机的 127.0.0.1:8766 也打不开 | 先运行 start.bat，查看启动窗口是否报错；端口占用时先退出旧服务 |
| 主机能开，其他设备超时 | 确认同一局域网、地址与端口正确；管理员运行 allow-lan.bat；排查访客 Wi-Fi/AP 隔离或企业网络隔离 |
| 显示 403 | IP、客户端子网或 Host 与配置不一致；重新配置所选网络并重启，不要使用旧地址 |
| 反复要求密码/401 | 主机运行 lan-info.bat 查看六位密码，用户名 gift；关闭旧标签页重新打开 |
| 连接中断提醒/请求超时 | 保留未保存编辑，确认主机仍运行；恢复后先查看最新状态，不自动重发登记 |
| 主机重启后提示连接已更新 | 本次操作未执行，编辑仍保留；再次明确点击保存或操作按钮 |
| IP 已变 | 重新运行 lan-setup.bat、allow-lan.bat，并通知其他设备新地址 |

这是可信局域网内的 HTTP 服务，不配置公网映射。不同 VLAN/子网默认不允许访问，应由网络管理员处理；不要为了连接而放开所有来源。

## 关闭局域网共享

正常退出工作台，双击 `lan-disable.bat`，再重新启动，恢复仅本机访问。可在该目录的管理员 PowerShell 中执行以下命令禁用本工具防火墙规则：

```powershell
powershell -ExecutionPolicy Bypass -File .\allow-lan.ps1 -Port 8766 -Disable
```

不会删除草稿、礼品、平台会话或防重复登记历史。
