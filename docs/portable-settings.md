# 便携版账号与浏览器配置

在目标电脑上双击 `settings.bat`，分别填写聚水潭、班牛账号密码，并设置各平台的“业务浏览器无头运行”。点击保存后，正常关闭并重启工作台生效。

便携版现在使用目标电脑安装的 Microsoft Edge，`portable.json` 中设置 `"browser": "edge"`。无需 U 盘 Chrome；不要把 ChromeDriver 配给 Edge。Selenium 自动检测 Edge 版本并联网下载匹配的 EdgeDriver，缓存位于 `data/selenium`。首次启动或 Edge 升级后可能需要等待驱动下载；目标电脑须允许 Selenium 访问微软驱动下载站点。

两平台使用独立的 `data/browser_edge` 配置，不打开或更改日常 Edge 的用户配置。旧 Chrome 登录目录保留但不再使用；换电脑后请重新配置账号并通过 `login.bat` 登录。现有无头选项同时适用于 Edge。电脑未安装 Edge 时先安装或修复 Edge；驱动下载失败时检查网络后重启浏览器，不要删除任务记录或重复提交订单。

配置统一保存在 `config/accounts.local.json`：

```json
{
  "version": 1,
  "accounts": {},
  "browser_headless": {
    "jushuitan": false,
    "banniu": false
  }
}
```

- `accounts` 初始为空。通过设置窗口保存后，每个平台会有 `username` 和加密的 `password_dpapi`，供原有自动登录机制使用。无需手动编辑密码密文。
- 密码输入不显示；留空保留已保存的密码。修改账号时必须填写新密码。两个平台在同一次保存中写入，保存失败不会留下部分设置。
- `browser_headless` 可以用记事本修改：`true` 表示隐藏业务浏览器，`false` 表示显示。必须使用 JSON 布尔值，不要加引号。默认两个平台都显示窗口。
- 此选项作用于登记、查询和复核使用的业务浏览器。`login.bat` 或工作台的登录助手始终显示窗口，以便处理验证码、扫码等。
- 无头模式不会绕过验证码，也不会自动重提失败订单。如果需要人工登录，先正常关闭工作台，通过 `login.bat` 登录并保存、关闭助手，再启动工作台；仍有问题时把对应平台无头模式关闭。
- 已有有效会话仍优先复用，修改账号密码不会自动退出平台的现有登录。若要切换到另一个平台账号，应在可见的登录助手中退出旧账号，登录新账号并保存会话。
- 密码由保存时的 Windows 用户通过 DPAPI 加密。换电脑或 Windows 用户后，需要在目标电脑重新输入并保存两平台密码；不要复制原电脑的加密密码当作可跨电脑使用的明文配置。
- `accounts.bat` 原有命令行账号设置入口继续可用，不会清除浏览器选项。不要上传 `accounts.local.json`、平台会话或业务数据到 GitHub。

设置入口仅在本机桌面使用，不通过局域网网页提供账号或密码读取接口。
